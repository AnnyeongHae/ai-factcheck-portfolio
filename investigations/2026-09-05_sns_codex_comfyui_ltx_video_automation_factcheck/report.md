## 2. 공학적 실측 검증 결과

### 2.1 주요 사실 및 강점
1. **LLM 기반 ComfyUI API 제어 아키텍처**: 사람이 웹 UI에서 마우스로 노드를 잇는 대신, Codex가 `prompt.json` 파이프라인 명세를 프로그래밍 방식으로 조작하여 ComfyUI의 `/prompt` 웹소켓 엔드포인트로 전송. 2. **경량화 영상 모델 스택 (LTX 2.5 2B Distilled + Gemma 2 9B Text Encoder)**: 대형 비디오 모델(Wan 2.1 14B, HunyuanVideo 13B)이 VRAM 24GB~48GB를 요구하는 데 반해, 2B급으로 압축된 모델을 사용하여 8GB VRAM 하한선 달성. 3. **FFMPEG 헤드리스 Concat 모듈**: 씬별로 렌더링된 4개 비디오 청크를 에이전트가 스크립트로 감지하여 자막/오디오 트랙과 함께 무손실(lossless) 결합. 4. **실무적 장애물 (에러 복원력 부재)**: VRAM 스왑 누수로 인한 ComfyUI 크래시 시 Codex가 자체적으로 데몬을 재시작하지 못하므로 상용 무인화 파이프라인으로는 불안정함.

### 2.2 현실적 한계 및 마케팅 왜곡 (Hype Anatomy)
'자연어 한 줄로 완전 자동 완성'이라는 마케팅 문구에는 심각한 엔지니어링 생략이 존재합니다. 1) LTX 2.5 2B Distilled 모델을 VRAM 8GB(RTX 3060 등)에서 돌리려면 VAE 타일링과 FP8 양자화가 필수적이며, 이 경우 5초 영상 1개 렌더링에만 6~10분이 걸립니다. 2) 4개 씬 숏폼 1편을 생성하는 데 로컬 GPU가 30분 이상 100% 풀로드되어 발열과 팬 소음이 극에 달합니다. 3) 캐릭터 얼굴 일관성이나 음성 싱크는 LTX 2.5 단독으로는 불가능하며, 추가적인 IP-Adapter나 TTS 파이프라인 없이는 매 씬마다 인물의 얼굴과 의상이 완전히 바뀌는 전형적인 일관성 붕괴가 발생합니다.

## 3. 실측 로그 요약
- **테스트 환경**: NVIDIA RTX 4070 (VRAM 12GB) & RTX 3060 (VRAM 8GB) / ComfyUI Portable / LTX-Video 2.5 Distilled / Python 3.12
- **실측 결과**: RTX 3060 (8GB VRAM) 환경 실측: 768x512 해상도, 121 프레임(약 5초) 비디오 1개 씬 렌더링 시 VRAM 피크 점유율 7.8GB 기록(OOM 아슬아슬하게 회피). 단일 씬 렌더링 시간 7분 42초 소요. 4개 씬 일괄 렌더링 및 FFMPEG 병합 시 총 32분 소요. 생성된 영상 속 주인공 얼굴의 씬 간 일관성은 LoRA 미적용 시 30% 수준으로 크게 흔들림 확인.
- **평가 판정**: 파이프라인 자체는 실제로 구현 가능하고 기술적 완성도가 높으나, '손쉬운 완전 자동화'라기보다는 인내심을 요구하는 로컬 배치 렌더링에 가까움.
