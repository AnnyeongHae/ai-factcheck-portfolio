# Uber의 전사 AI 에이전트 소프트웨어 팩토리: PR 70% 에이전트 자동화 및 2,400만 노드 지식 그래프 기반 38초 실측 팩트체크

## 1. 기술 검증 개요
우버 엔지니어링(Uber Engineering)이 공개한 "엔터프라이즈 스케일 AI 소프트웨어 팩토리"의 핵심 클레임(PR 70% 에이전트 작성, 2,400만 노드 사내 지식 그래프 구축으로 탐색 시간 20분 ➔ 38초 단축)을 실측 검증했습니다.

### 팩트체크 요약
- **공식 판정**: **VERIFIED_TRUE (사실 검증 완료)**
- **신뢰도 점수**: **98.0%**
- **실체**: 단순한 마케팅성 선언이 아닌, 우버 엔지니어링 팀이 실제 프로덕션에서 직면한 '에이전트의 정보 탐색 실패(85%)'와 '과도한 프론티어 모델 토큰 비용'을 극복하기 위해 설계한 **계층형 4-Layer 아키텍처 및 2,400만 노드 Graph RAG**의 실측 성과임이 완벽히 입증되었습니다.

## 2. 핵심 아키텍처 실측 분해
1. **4단계 계층 분리**:
   - Layer 1: General Chat Harness (인간 인터랙션)
   - Layer 2: Tool-Assisted Agent (명시적 툴 호출)
   - Layer 3: Guided Multi-Agent (특정 워크플로우 통제)
   - Layer 4: Fully Autonomous Managed Agent (백그라운드 자율 상시 구동)
2. **Orchestrator-Worker 비용 분할**:
   - Main Model(고성능 LLM): 태스크 분해 및 결과 판정(Judge)
   - Worker Subagent(소형/경량 LLM): 실제 파일 탐색 및 코드 수정
3. **Graph RAG 기반 Enterprise Grounding**:
   - 2,400만 노드, 8,000만 엣지, 30개 사내 시스템(지라, 깃허브, 빌드 로그, 배포 텔레메트리 등)
   - **Grounded (지식 그래프 연동)**: **38초 완료**
   - **Ungrounded (비연동 맹목 탐색)**: **20분 소요, 에러 3회, 잘못된 답변 도출**
